ЧЕРНОВОЙ ПАК — НЕ ФИНАЛЬНЫЙ НАБОР РАКУРСОВ

Содержимое:
native/ — вырезанные изображения в исходном разрешении.
sprites_1024/ — те же изображения на прозрачных холстах 1024x1024.
sheet_3x2.png — общий лист: три столбца, две строки, ячейки 1024x1024.
source_sheet.png — лист, из которого вырезаны новые изображения.
reference_original.png — исходный персонаж из предыдущего сообщения.
manifest.json — размеры и происхождение каждого кадра.

Ограничения:
Изображения вырезаны из общих сгенерированных листов. Их нативное
разрешение меньше 1024x1024; увеличение не добавляет новых деталей.
Отдельные ракурсы близки друг к другу. Внешность, одежда, цвета и
аксессуары не везде совпадают с исходными персонажами.
Это черновые варианты, а не проверенный набор для финальной игры.
Нумерация view_01... отражает порядок в источнике, а не точные углы.
Зеркальные копии не добавлялись.
PNG содержат альфа-канал; изображения очищены от общего фона.

Для курьера:
Пять изображений вырезаны из сгенерированного листа. Шестой файл,
view_06_original_reference.png, — исходный ракурс, а не новый шестой вид.
Таким образом, комплект не является набором из 60 новых ракурсов.
