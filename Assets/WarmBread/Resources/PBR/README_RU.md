# Локальные PBR-материалы

В папке находятся четыре бесшовных набора 1024×1024:

- `ConcretePavement` — потёртый бетон и тротуар;
- `WornPlaster` — старая светлая штукатурка;
- `GreenKioskPaint` — зелёная краска металлического киоска;
- `RustedMetal` — ржавые рамы, петли и технические детали.

Все карты созданы специально для проекта процедурно и не требуют внешней лицензии. Файлы `_Height` автоматически импортируются Unity как normal map. Команда `Warm Bread > Art > Rebuild PBR Materials` создаёт URP Lit-материалы с настроенным tiling, normal strength, metallic и smoothness. Runtime автоматически добавляет микрорельеф существующим материалам киоска, тротуара, асфальта и зданий, не заменяя нарисованные авторами base-color карты.

Рекомендация: назначить `MAT_GreenKioskPaint` корпусу ларька, `MAT_RustedMetal` рамам и мелким металлическим деталям, `MAT_ConcretePavement` земле возле окна, `MAT_WornPlaster` соседним стенам.
