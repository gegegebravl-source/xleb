# Тёплый хлеб — релизный чек-лист

Проект версии **2.0.0** подготовлен для **Unity 6000.3.24f1 LTS** и Windows x64.

## Первый импорт

1. Установить Unity 6000.3.24f1 с модулями Windows Build Support (IL2CPP) и Microsoft Visual C++ Redistributable.
2. Открыть корень проекта в Unity Hub и дождаться окончания импорта пакетов и шейдеров.
3. Убедиться, что консоль не содержит ошибок компиляции.
4. Выполнить `Warm Bread > Release > Validate Project`.
5. Выполнить `Window > General > Test Runner` и запустить EditMode-тесты.

## Приёмка игры

- Главное меню, пауза, настройки, управление с клавиатуры/мыши и контроллера.
- Полный игровой день: открытие ларька, покупка, доставка, продажа, закрытие.
- Сохранение, перезапуск игры и восстановление состояния.
- Русская и английская локализация: переносы строк и отсутствие обрезанного текста.
- 1920x1080, 2560x1440, 3840x2160 и 1280x720 в окне.
- Проверка на видеокарте минимальной конфигурации и отсутствие заметных зависаний при первой загрузке сцен.
- Звук, FMOD-банки и корректное поведение при устройстве вывода без звука.

## Сборка Windows

В Unity: `Warm Bread > Release > Build Windows x64`.

Либо из PowerShell:

```powershell
.\Tools\run-tests.ps1 -UnityPath "C:\Program Files\Unity\Hub\Editor\6000.3.24f1\Editor\Unity.exe"
.\Tools\build-windows.ps1 -UnityPath "C:\Program Files\Unity\Hub\Editor\6000.3.24f1\Editor\Unity.exe"
```

Результат появится в `Builds/Windows`. Перед публикацией проверить сборку на чистом компьютере. Для проблемных GPU игру можно запустить с аргументом `--safe-mode`.

## Перед загрузкой в магазин

- Заменить `com.warmbread.game`, если у команды уже есть собственный reverse-DNS идентификатор.
- Заполнить название студии, юридические сведения, страницу поддержки и возрастной рейтинг.
- Сделать подписанную финальную сборку и просканировать её антивирусом.
- Подготовить скриншоты, трейлер, описание и системные требования.
- Проверить лицензии всех добавленных после этой версии ассетов.
