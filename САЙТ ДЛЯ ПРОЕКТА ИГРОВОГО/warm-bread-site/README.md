# Тёплый хлеб — release website

Полностью автономный промо-сайт игры «Тёплый хлеб — туда, где тебя помнят».

## Быстрый запуск

Откройте `index.html` двойным кликом — сайт работает без сборки и внешних библиотек.

Для локального сервера:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Подключение страницы магазина

Откройте `script.js` и замените:

```js
const STORE_URL = "";
```

на ссылку Steam / VK Play / другой страницы игры. Все кнопки «В желаемое» и «Страница игры» автоматически начнут вести туда.

## Что внутри

- адаптивная desktop / tablet / mobile вёрстка;
- атмосферный hero-блок с параллаксом и анимацией пара;
- интерактивная шкала смены 06:00—20:00;
- интерактивный интерфейс старого рабочего ПК;
- персонажи района;
- коллаж предметов начала 2000-х;
- работающий CRT-телевизор с 4 каналами и 8-кадровыми sprite sheet-анимациями;
- галерея хлеба;
- журнал историй;
- release CTA и модальное окно-заглушка магазина;
- favicon, webmanifest, robots.txt;
- reduced-motion режим для accessibility;
- без CDN, npm, фреймворков и внешних шрифтов.

## Структура

- `index.html` — разметка;
- `styles.css` — дизайн и адаптив;
- `script.js` — интерактивность;
- `assets/` — оптимизированные игровые изображения;
- `favicon.svg`, `site.webmanifest`, `robots.txt` — release-служебные файлы.

## Публикация

Папку можно загрузить как статический сайт на GitHub Pages, Netlify, Cloudflare Pages, Vercel Static или обычный хостинг. Корневой файл — `index.html`.
